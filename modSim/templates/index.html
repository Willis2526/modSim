Direct Read / Write

Reads or writes a specific address directly, independent of any simulation rule. Bypasses the rule engine — if the address is also covered by an active rule, the simulation loop will overwrite a write here on its next tick (~1s).

Address Notes
  • Each server has an Addressing mode (Servers page).
  • 0-based (default): rule address N is register N.
  • 1-based: rule address N is register N-1; the Modbus wire stays 0-based, so a client reads it at N-1.
  • Ignition OPC paths like IR1136 map to 0-based address 1135.
  • Use address_end to configure a contiguous range in one rule.
  • Set ir_size ≥ highest address + 1 when configuring slaves.
Example — multiple register rules
{
  "registers": [
    // Static flag registers (IR76–IR87, 0-based addrs 75–86)
    {"server_id":0,"slave_id":1,"register_type":"ir",
     "address":75,"address_end":86,"simulate":true,
     "simulation_mode":"static","simulation_config":{"value":0}},

    // Slow sine — SOC at IR1141 (0-based 1140), 5-min period
    {"server_id":0,"slave_id":1,"register_type":"ir",
     "address":1140,"simulate":true,"simulation_mode":"sine",
     "simulation_config":{"amplitude":2,"offset":7,"period":300}},

    // Equation-based sawtooth across holding registers
    {"server_id":0,"slave_id":0,"register_type":"hr",
     "address":0,"address_end":49,"simulate":true,
     "simulation_mode":"equation",
     "simulation_config":{"equation":"(x + address) % 1000"}}
  ]
}
